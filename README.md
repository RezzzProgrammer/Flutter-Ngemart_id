# Ngemart.id

Aplikasi mobile e-commerce sederhana berbasis Flutter dengan tema Pastel Drift. Data produk di ambil dari API publik DummyJson(https://dummyjson.com/products)

## Fitur

- Splash Screen dengan animasi progress bar
- Daftar Produk dua kolom, pencarian, dan filter kategori
- Halaman detail: galeri gambar, pilihan warna dan ukuran, stepper jumlah (maksimal 5), indikator stok
- Wishlist dan Keranjang
- Tampilan loading, error, dan kosong

## Teknologi

Flutter, Provider(state management), Dio(HTTP), cached_network_image, google_fonts

## Struktur Folder

lib/core, lib/models, lib/services, lib/repositories, lib/providers, lib/views, lib/widgets

## Cara Menjalankan

1. Pasang Flutter SDK
2. Jalankan "flutter pub get"
3. Jalankan "flutter run"
